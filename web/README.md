# Downtown Denver Digital Twin (web)

Next.js 15 app: Mapbox 3D map + Cesium globe.

## Run

```bash
cd web
copy .env.example .env.local
# put your Mapbox (+ optional Cesium Ion) token in .env.local
npm install
npm run dev
```

Open http://localhost:3000

## Layout

```
web/
├── src/
│   ├── app/              # Next.js routes / layout
│   ├── components/       # Map, Globe, shared Twin UI
│   └── lib/              # camera sync, street routing helpers
├── public/
│   ├── data/             # buildings.geojson, meta.json, overlays
│   ├── icons/            # traveler PNGs
│   └── cesium/           # generated by postinstall (do not hand-edit)
└── scripts/
    └── copy-cesium.mjs   # copies Cesium static assets on npm install
```

## Data

Static GeoJSON in `public/data/` is produced from `../aoi/` scripts.
